O que é o HTML

HTML é uma linguagem de marcação usada para estruturar paginas. Ele define titulos, paragrafos, imagens, links, etc.

O que é CSS

CSS é uma linguagem usada para estilizar paginas HTML. Ele controla cores, fontes, espaçamentos e o layout dos elementos.
